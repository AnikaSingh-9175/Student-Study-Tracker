# Student-Study-Tracker
A clean, Python-based study tracker designed to record, track, and manage daily study time effectively. This tool helps students monitor their productivity and maintain a consistent learning schedule.

## ✨ Features
* *Interactive CLI Interface:* Quick and easy terminal prompts to log study sessions.
* *Smart Performance Evaluation:* Uses conditional data logic to analyze total study hours and output custom motivational performance metrics.
* *Data Persistence (Planned):* Future updates will integrate structured data storage to export daily logs directly into Excel-compatible sheets.

## 🛠️ Tech Stack & Skills
* *Language:* Python 3
* *Concepts Used:* User Input Parsing, Dynamic Data Type Casting (float), and Conditional Logic Flow (if-elif-else).
